## Eval result JSON structure

Each `results/v1_results.json` is an array of eval results. Each result contains:

- **Agent output**: answer, confidence, sources cited, model reasoning, declined flag
- **Searches**: every Wikipedia query made — query string, article title, URL, and the full retrieved content (used by the groundedness judge to verify claims trace back to Wikipedia)
- **Trace**: compact step-by-step agent reasoning — what the model was thinking at each step and which tool it called. Always embedded; not optional.
- **Deterministic checks**: pass/fail assertions with failure tags
- **Judge results**: score (1–5), reasoning, and failure tags from each of the four judges
- **Failure tags**: unified taxonomy across checks and judges for pattern analysis
