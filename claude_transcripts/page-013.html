You're right, it's a bad test case. The problem is structural: SQ-H and SQ-I are context-dependent SQuAD questions that only make sense with the specific Wikipedia passage the question was derived from. Without that context:

  • "What battle took place in the 10th century?" is a perfectly valid question — there are real 10th century battles (Battle of Lechfeld 955 AD, Battle of Maldon 991 AD). The agent might correctly answer one of those, and we'd mark it wrong.
  • "What treaty was established in the 9th century?" — same problem. Treaty of Verdun, 843 AD. Legitimate correct answer we'd penalize.

The false premise only exists relative to the SQuAD passage (which implies the question is about Hastings / Saint-Clair-sur-Epte). Strip that context and they're just open questions with real answers. We're essentially testing whether the agent knows the "right" wrong answer.

The other SQuAD cases don't have this problem — the false premises are universal (oxygen isn't the most abundant element regardless of context, France is never a region of anything, the immune system protects against disease not cold in all contexts).
